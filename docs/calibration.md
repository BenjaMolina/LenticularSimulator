# Capture the first 50 LPI print baseline

Use this two-view target to check scale and record where each stripe is visible. It is a measurement aid, not an automatic calibration or a ghosting report.

## Generate and print

1. Load [view-a.png](../public/calibration/view-a.png) first and [view-b.png](../public/calibration/view-b.png) second. They are A4-proportioned source images; use the app's interlaced PNG for printing.
2. Start at 50 nominal LPI and 600 PPI. Use measured effective LPI if known; otherwise record that 50 LPI and zero offset are trial settings.
3. Generate and download the print PNG. Print at **actual size / 100%** without fit-to-page or automatic scaling. Measure the gap between the bottom ticks: it should be 100 mm. Record any deviation before interpreting the target.
4. Align the vertical lenticules with the vertical print stripes and record which side faces the observer. Do not change alignment between captures.

## Photograph and record

- Keep illumination, distance, exposure, focus, and white balance fixed. Aim at the center and record the true horizontal angle relative to the sheet normal. Start at −20°, −10°, 0°, +10°, and +20°; add smaller steps around any transition.
- The two small top patches are white and black references. The large upper patch is white in view A only; the large lower patch is white in view B only. Sample the interiors, not the patch borders or the tick marks.
- Bring back the original photos and the angle for each, plus the selected PPI, effective LPI, offset, ruler measurement, sheet identification, and printer/media/settings. Record any glare or clipping. If available, keep RAW files for later intensity measurements.

The next comparison uses those observations to constrain the optical model. Do not infer physical crosstalk percentages from the illustrative preview or from camera JPEG brightness alone.
