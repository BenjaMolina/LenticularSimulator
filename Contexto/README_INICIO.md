# Paquete de continuidad — Simulador óptico lenticular

Este paquete conserva el contexto del diálogo para transferirlo a otro agente en tu equipo. No contiene código de la aplicación; el proyecto todavía se encuentra en fase de definición.

## Orden recomendado de lectura por el nuevo agente

1. `CONTEXTO_AGENTE.md`: situación, decisiones, restricciones, criterios técnicos y tareas pendientes.
2. `PROMPT_IMPLEMENTACION_REACT_JS.md`: solicitud de implementación completa, tal como quedó redactada en el chat.
3. `DECISIONES_PROYECTO.json`: información estructurada para herramientas/agentes.
4. `TRANSCRIPCION_CONVERSACION.md`: reconstrucción cronológica del diálogo y su evolución.

## Mensaje corto que puedes copiar en tu agente

> Quiero retomar el proyecto Lenticular Optical Simulator. Lee todos los archivos de este paquete, empezando por `CONTEXTO_AGENTE.md`, y conserva todas las decisiones ya tomadas: React + JavaScript (sin TypeScript), Vite, 50 LPI nominales, lentes verticales, impresora no definida y meta de una simulación óptica calibrable para predecir/analizar ghosting. No confundas previsualización animada con reproducción física validada. Antes de programar explica el modelo, las limitaciones y los criterios de prueba; después prepara el MVP funcional por fases.

La transcripción es una recopilación textual de contenido visible y no una exportación oficial literal de todos los metadatos, imágenes o controles interactivos del chat.
